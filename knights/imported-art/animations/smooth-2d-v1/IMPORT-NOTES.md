# ANTHOLD — 41 smooth 2D animation drafts

41 knights, five moves per knight, eight frames per move. Full sheets: 2048×1280; cells: 256×256; columns: 8; rows: walk, attack, special, hit, death. Each move is also a 2048×256 strip. Transparent PNG, zero spacing. Suggested starting speeds: walk 8 fps, other moves 10 fps. Loop walk only; hold final death frame. Bottom-centre cell pivot. Facing generally right/three-quarter; mirror in engine as needed.

## Not production-final
AI-assisted frames can change grips, crests, weapon shapes and apparent foot position. Some effects cross cell boundaries and some walks have weak leg alternation. Equal-cell slicing does not repair these drawing issues. Review and redraw before shipping; no claim of engine-tested readiness. No idle cycle is included in this pack. The game repository's current weapon tables differ from some earlier approved artwork; these assets preserve that artwork, not the newer procedural-rig weapon table. Importing files does not wire them into game playback.
