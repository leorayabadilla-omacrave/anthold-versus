# Imported ANTHOLD art

New art made in Lovable, added without changing any existing game file. Files whose exact contents were already in the repo were skipped.

- `final/`, `species*/`: character sheets for the 8 classes and 33 species
- `sprites/game-ready/`, `species-game-ready-v2/`, `species-pixel-art/`: smooth and pixel sprites and 4-pose sheets
- `class-bases/sheets/`: 8 bases with damage states
- `animations/smooth-2d-v1/`: 41 knights x 5 moves x 8 frames (see IMPORT-NOTES.md)

The animation sets are AI-assisted drafts: some grips, crests and steps change between frames and need touch-ups before shipping. The game does not load these files yet.
